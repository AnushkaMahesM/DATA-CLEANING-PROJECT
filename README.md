CSV Data cleaning and Visualization with Python

A beginner-freindly data analysis focused on importing, cleaning, transforming abd visualising CSV data using python and pandas.

Overview:

Demonstrates a very simple end to end data preperation and analysis workflow using a CSV dataset. The project starts with a raw dataset and uses Python to prepare the data for analysis by identifying and handling common data-quality issues such as missing values, duplicate records, inconsistent columns, and date formats.

After cleaning the dataset, I created visualizations to explore the data and exported the cleaned dataset for further use.

The workflow

Raw CSV Data - Import with Pandas - Inspect & Understand Data - Clean & Transform - Handle Missing Values - Remove Duplicates - Convert Data Types - Visualize Data
- Export Clean Dataset

Technologies used: Python, Pandas, Jupyter Notebook, VS Code & Matplotlib
